# 도보 길찾기(S07) 전제 (필요할 때만 연다)

**카카오가 공개한 길찾기 REST API 는 자동차 경로다. 도보는 공개 API 가 없다.** 어느 제공자를 쓰든
(카카오 협의 · TMAP 보행자 API) REST 키를 보관할 **서버 프록시**를 반드시 거친다 — REST 키는 브라우저에
들어갈 수 없다. 경로는 `screens/main/data/walkRoute.js` 한 곳에서만 가져오고, 화면은 그것이 실 응답인지
예시 경로인지 알지 못한다. `config.js` 의 `WALK_ROUTE_ENDPOINT` 를 채우면 전환되며 **화면 코드는 손대지 않는다.**
