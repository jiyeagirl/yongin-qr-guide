Primary action control — flat filled surfaces, no border or shadow.

```jsx
<Button variant="primary" size="lg" icon="edit_note" block>실증 참여 신청하기</Button>
```

variant: primary | secondary | soft | outline | ghost | danger. size sm/md/lg (40/48/56px). Only `outline` carries a border (1px --border-strong). Press scales to 0.96. Full-width `block` for the bottom CTA of a screen.
