The only icon primitive — a Lucide line glyph.

```jsx
<Icon name="heart-pulse" size={24} />
```

Requires the Lucide UMD script on the page. Never set `strokeWidth`, never wrap an icon in a filled/tinted square, never mix icons with the 조아용 character. Sizes: 16 inline, 20 rows, 24 tabs/headers, 28 tiles.
