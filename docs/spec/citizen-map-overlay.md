## 1. 셸의 겹침 구조

루트(`MainApp`)는 세로 flex 컨테이너다: 폭 100% · 최대 폭 `--screen-max`(430px) · 높이 100% · `overflow:hidden`.

| 위에서 아래 | 내용 | z |
|---|---|---|
| 컨텍스트 바 | 한 줄 띠 「QR 스캔 지점 기준 안내 · {기준점 이름}」 + 조아용(hello 22px). QR 지점에 `bannerLabel` 이 있으면(현재 `qr-004`) 이름 없이 그 문구(「둔전 골목형 상점가 기준 안내」)만 적는다. 세 탭 모두에 있다. 높이는 내용을 따른다(고정 없음) | 300 (`--z-filter`) |
| 지도 영역 | `position:relative`, 남는 높이 전부. **시트 % · 지도 패딩 · 플로팅의 기준 컨테이너**다 | — |
| 하단 탭바 | 지도 영역의 **형제**. 높이 `--tabbar-h`(64px) + 안전영역 | 450 |
| S14 대화상자 · 코치마크 | 루트의 자식, 조건부 | 600 |
| 상세 오버레이 | 루트의 자식 (`DetailPage`) | 600 |
| 토스트 | 탭바 위 `calc(탭바 높이 + 16px)` 에 가운데. 클릭 통과(`pointer-events:none`) | 700 |

지도 영역 안의 층(아래에서 위):

| 층 | 부품 | z |
|---|---|---|
| 지도 베이스 | `KakaoMap` (`position:absolute; inset:0`) | 100 |
| 마커 · 경로 · 구역 면 | 지도 SDK 가 직접 그림 | 200 대역 |
| 상단 필터 바 | `MapFilterOverlay` (위에 붙음, 배경 패널 없이 알약만) | 300 |
| 미리보기 카드 · 플로팅 컨트롤 | `MapPreviewCard` · `FloatingControls` | 400 |
| 바텀시트 | `Sheet` | 500 |
| 둘러보기 정보 패널 | `DiscoverPanel` (흐름 안, 스크롤 패널) | 지도 영역 안 |

- z 값은 `tokens/layers.css` 의 9개뿐이다: 지도 100 · 마커 200 · 필터 300 · 플로팅 400 · 탭바 450 · 시트 500 · 팝오버 550(칸이 여는 목록) · 모달 600 · 토스트 700. 부품 안에서 제 것끼리 앞뒤를 가리는 작은 수는 이 표 밖이다.
- 탭바가 시트의 형제이므로 시트가 전체 스냅이어도 탭바를 덮지 않는다. 전체 스냅에서도 탭을 바꿀 수 있다.
- 상세 오버레이(600)는 탭바(450) · 시트(500)를 모두 덮는다. 셸은 언마운트되지 않는다.

## 2. 바텀시트 (`Sheet`)

### 2-1. 3단 스냅

| 스냅 | 시트 높이(지도 영역 기준) | 지도 노출 |
|---|---|---|
| 접힘 `collapsed` | 18% (`--sheet-collapsed`) | 82% |
| 절반 `half` | 37% (`--sheet-half`) | 63% |
| 전체 `full` | 100% − **상단 필터 바 실측 높이** (`topInset`) | 0% |

- 값은 `layers.css` 가 단일 출처이고, `Sheet.SNAP_RATIO`(0.18 / 0.37 / 1)는 드래그를 놓았을 때 어느 단계로 붙일지 정하는 같은 값이다. 둘은 같아야 한다.
- 비율은 뷰포트가 아니라 지도 영역 기준이다(지도 영역은 컨텍스트 바와 탭바를 뺀 높이).
- 시트는 상단 필터 바를 덮지 않는다. 필터 바가 없는 탭(둘러보기 · 상점가 없음 상태)은 `topInset` 이 0 이다.
- 진입 시 절반. 탭을 바꾸면 절반으로 돌아간다. 둘러보기 탭에는 시트가 없다.
- 스크림은 쓰지 않는다 (전체 스냅은 지도를 완전히 덮는다).

### 2-2. 조작

| 조작 | 동작 |
|---|---|
| 핸들(44×5) 짧게 누름 | 접힘 → 절반 → 전체 → 접힘 순환 |
| 핸들 끌기 | 손가락을 따라 높이가 변한다. 아래 한계 = 지도 영역 × 0.18 × 0.6, 위 한계 = 지도 영역 − `topInset`. 놓으면 **가장 가까운 스냅 비율**로 붙는다 |
| 키보드(핸들에 초점) | Enter / Space 순환, ↑ 한 단계 위, ↓ 한 단계 아래 |
| 전체 스냅 헤더 [지도] (`map` 아이콘) | 절반으로 |
| 전환 | 높이 트랜지션 320ms (`--dur-slow`) `--ease-out`. 끄는 중에는 트랜지션 없음 |

- 헤더: 제목(19px 굵게) · 제목 줄 오른쪽 끝 `titleAside` · 전체 스냅일 때만 [지도] 단추 · 제목 아래 `headerExtra`. 시트 제목: 공공시설 탭 「주변 공공시설」(유형을 골랐으면 「주변 AED · 화장실」, 4종 모두 고르면 전체와 같음) / 상점가 탭 현재 상점가 이름(없으면 「상점가」).
- `scrollKey` 가 바뀌면 시트 본문 스크롤을 맨 위로 되돌린다 — 공공시설: `facility|유형|반경|쪽`, 상점가: `district|업종|온누리|정렬|검색어|쪽`.
- 시트는 자기 실측 높이를 `onHeightChange` 로 올려보낸다(ResizeObserver + 스냅 전환 동안 프레임마다). 지도 패딩 · 카드 · 플로팅이 이 값을 쓴다.

## 3. 지도 패딩 (마커가 가려지지 않게)

| 값 | 식 |
|---|---|
| `gap` | `--map-pad-gap` (24px) 를 읽는다 |
| `mapPadTop` | 상단 필터 바가 있으면 필터 바 실측 높이, 없으면 0 → + `gap` |
| `mapPadBottom` | 시트 실측 높이 + (미리보기 카드가 떠 있으면 카드 실측 높이 + `gap`) + `gap` |

- 카카오맵에 `setPadding` 이 없어 `focus(lat,lng)` 가 투영 좌표로 계산한다: 마커의 화면 좌표 P 에서 `y += (bottomPad − topPad)/2` 한 지점을 지도 중심으로 `panTo`. 마커는 필터 바 아래 ~ 시트 위 띠의 한가운데로 온다.
- 레이어 토큰의 `--map-pad-collapsed/half/full`(22% / 41% / 41%)은 코드가 읽지 않는다. 실행 시에는 위 실측 px 만 쓴다.
- 카드가 뜬 뒤 · 시트 스냅이 바뀐 뒤(선택이 남아 있고 전체 스냅이 아닐 때) 340ms(`SHEET_SETTLE`) 뒤에 선택 마커를 다시 시야로 올린다.
- 필터 바 높이는 `ResizeObserver` 로 잰다 — 공공시설 탭(검색창 없음)과 상점가 탭의 바 높이가 다르다.

## 4. 상단 필터 바 (`MapFilterOverlay`)

| 탭 | 구성 | 비고 |
|---|---|---|
| 상점가 | 검색창 + 업종 칩 줄(`[전체]` + 7종) | 상점가 없음(S03-E)에서는 바 전체 없음. 다른 상점가 카드가 떠 있는 동안은 **칩 줄만** 내리고 검색창은 남긴다 |
| 공공시설 | 시설 유형 칩 줄만(`[전체]` + 4종, 검색창 없음) | |
| 둘러보기 | 없음 | 둘러보기 전환 시 필터 바 높이는 0 으로 친다 |

- 지도 위에는 「지도를 보며 범위를 좁히는 것」만 둔다. 온누리 칩 · 정렬은 지도 위에 없다(S15 목록 위). 안내 반경 고르개는 시트 헤더에 있다.
- 칩 줄: 0건인 칩은 숨긴다. 여럿 고르기(빈 선택 = 전체, 칩끼리 OR). `[전체]`는 맨 왼쪽에 서고 켜져 있을 때 다시 눌러도 꺼지지 않는다. 개수는 보이는 칩들의 합이다. 줄의 양 끝은 검색창과 같은 세로선이고, 더 밀 수 있는 동안만 끝 12px 이 흐려진다.
- 검색창을 누르면(포커스) 또는 Enter 를 치면 S15(`#/stores`)가 열린다. 입력은 S15 의 검색창에서 받는다.

## 5. 미리보기 카드 · 선택 · 시트 연동

### 5-1. 카드

- 조건: `selected` 가 있고 시트가 전체가 아니며 둘러보기 탭이 아닐 때.
- 위치: 좌우 20px, 아래 = 시트 실측 높이 + 12px(`--float-gap`), z 400. 높이에 트랜지션을 걸지 않는다(시트 윗변을 그대로 따라간다).
- 내용: 아이콘(점포 업종 · 시설 유형, 상점가는 사진 자리 64px) · 이름 · `업종/유형 · 약 {m}m, 도보 {n}분`(거리가 있을 때) · 주소 또는 위치(시설은 `place || addr`) · 버튼 · [×]. 점포의 온누리 배지는 이름 옆, 상점가는 「점포 N곳, 온누리 N곳」 줄. 버튼은 `xs` 크기.

| 대상 | 버튼 |
|---|---|
| 점포 | [길찾기] → `goRoute` · [상세 보기] → `#/store/:id` |
| 시설 | [길찾기] · [상세 보기] → `#/facility/:id` |
| 상점가 | [상점가 안내] 하나 → `#/district/:id` |

### 5-2. 선택과 시트 (`pickOnMap`)

- 마커 · 목록 행 · 카드 진입은 모두 `pickOnMap(item)` 으로 모인다 (점포 `pickOnMap`, 시설 `pickFacility`, 상점가 `pickDistrict`).
- 시트가 접힘이면 즉시 카드를 띄운다. 그 밖이면 현재 스냅을 `restoreSnap` 에 적고 시트를 **접힘으로 내린다**.
  - 절반 → 접힘: 카드를 바로 띄운다.
  - **전체 → 접힘: 시트가 멈춘 뒤(340ms) 카드를 띄운다** (카드가 시트 윗변에 얹혀 있어 바로 띄우면 화면 위에서 흘러내린다). 카드와 마커 이동(`focus`)이 함께 미뤄진다.
- 카드를 띄운 두 프레임 뒤 `focus` 로 그 마커를 시야 띠 가운데로 옮긴다.
- 카드 [×] (`closePreview`): 선택 해제 · 카드 높이 0 · `restoreSnap` 이 있으면 그 스냅으로 되돌린다. 사용자가 시트를 직접 끌었으면(`changeSnap`) `restoreSnap` 과 대기 중인 선택을 버린다.
- 시트를 **전체로 올리면 선택을 버린다**(카드를 감추는 것이 아니라 `selected = null`). 다시 보려면 목록 행을 누른다.
- 탭을 바꾸면 선택 · `restoreSnap` 을 버리고 시트는 절반이 된다.
- [스캔 위치로] 를 누르면 선택 해제 · `restoreSnap` 버림 · 시트 접힘 · 지도 리셋.

## 6. 플로팅 컨트롤

지도 위에 뜨는 버튼은 **[스캔 위치로] 하나**뿐이다 (`qr-code` 아이콘 + 글자, 목록 토글 버튼은 없다 — 시트 스냅이 맡는다).

| 항목 | 규칙 |
|---|---|
| 자리 | 오른쪽 `--float-inset`(16px). 아래 = `clamp(12px, 시트 높이(+카드 높이+gap) + 12px, 100% − 필터 바 높이 − 기둥 실측 높이 − 12px)` — 시트 윗변(카드가 있으면 카드 윗변)에 붙어 함께 움직인다 |
| 보이는 조건 | 앵커(QR 지점)가 **지도 칸 밖**으로 나갔고(`anchorOff`) 시트가 전체가 아닐 때만. 아닐 때는 `opacity:0` + `pointer-events:none` (언마운트하지 않아 자리와 앵커링을 유지) |
| 앵커 이탈 판정 | `KakaoMap` 이 `bounds_changed` 마다 앵커의 화면 좌표를 재서 **지도 칸 전체 기준**(가장자리 28px 안쪽을 벗어나면 이탈)으로 판정하고, 값이 뒤집힐 때만 알린다. 지도가 `display:none`(칸 0)이면 마지막 값을 유지한다 |
| 모양 | 보이는 알약 34px (반투명 흰색 .82 + 흐림, 얇은 테두리, 카드 그림자, 12px 글자, 14px 아이콘), 눌리는 자리는 위아래 5px 투명 여백으로 44px |
| 누르면 | 선택 해제 · 시트 접힘 · 지도를 기준점으로(`reset` = `focus`) · 토스트 「QR스캔 위치로 이동했습니다」 |
| QR 지점별 문구 | QR 지점에 `backLabel` 이 있으면(현재 `qr-004`: 「상점가 중심으로」) 아이콘이 `map-pin`, 버튼 글자 · 라벨이 그 문구, 토스트가 「{backLabel} 이동했습니다」 |
| 트랜지션 | 위치에는 없다. `opacity` 만 200ms |
| 둘러보기 탭 | 없음 |

## 7. 지도 인스턴스 규칙

| 규칙 | 내용 |
|---|---|
| 셸 지도는 하나 | 한 번 만든 뒤 탭 전환 · 오버레이 열고 닫기로 다시 만들지 않는다. 둘러보기 탭에서는 `display:none` 으로 감추기만 한다. 다시 보일 때 `ResizeObserver` 가 `relayout()` 한다 |
| 초기값 | 중심 = 기준점(`DUNJEON.anchor`), 레벨 `MAP_LEVEL`(4, 반경 약 500m), 최대 레벨 12 |
| 지도 SDK | `loadKakaoMaps(KAKAO_APP_KEY)` 가 `dapi.kakao.com` 에서 한 번만 받는다(라이브러리 `clusterer`, `services`, `autoload=false`). 같은 약속을 공유하고, 실패는 캐시하지 않아 다시 시도할 수 있다. 10초 안에 초기화가 끝나지 않으면 실패 |
| SDK 실패 | `KakaoMap` 이 `MapCanvas`(목업)로 대체되어 격자 바탕 + 기준점 표시 + 「지도를 불러오지 못했습니다 · {사유}」 를 그린다. 시트 · 필터 · 목록은 그대로 동작하고 마커는 그려지지 않는다 |
| 도메인 | JavaScript 키는 소스에 있고, 카카오 콘솔의 SDK 도메인에 접속 출처(origin, 포트 포함)가 등록되어야 지도가 뜬다 |
| 코스 상세(S08) · 길찾기(S07) | 각자 `KakaoMap` 인스턴스를 따로 만든다(셸 지도의 카메라 · 레이어를 건드리지 않기 위해). 둘 다 비율 4:3, 높이 최대 46vh, 레벨 3 |
| 지도 조작 API(`mapRef`) | `focus(lat,lng)` · `setView(lat,lng,level)` · `fitTo(points,{top,bottom})` · `reset()` |

## 8. 탭 전환과 지도

`changeTab(id)` (같은 탭이면 아무 일 없음):

1. 선택 해제, `restoreSnap` 버림, 시트 절반.
2. 지도가 만들어져 있고 새 탭이 **둘러보기가 아니면** 카메라를 기준점 + `TAB_MAP_LEVEL[id]`(공공시설 4 · 상점가 4)로 되돌린다(`setView`).
3. 둘러보기로 갈 때는 카메라를 건드리지 않는다(지도는 감춰진 채 마지막 자리 유지). `TAB_MAP_LEVEL.discover`(7)는 정의돼 있으나 쓰이지 않는다.
4. 같은 탭 안에서 필터를 바꿔도 카메라는 움직이지 않는다.

- 탭별 상태는 탭을 오가도 남는다: 업종 칩 · 온누리 · 검색어 · 정렬 · 점포 쪽 번호 · 시설 유형 칩 · 시설 쪽 번호 · 안내 반경 · 원거리 안내 닫힘 · 축제 배너 닫힘. 조건이 바뀌면 해당 쪽 번호는 1 로 돌아간다(점포: 업종 · 온누리 · 검색어 · 정렬, 시설: 유형 · 반경).
- 스크린리더 상태 문구(`aria-live`): 「{탭} 탭 · 목록 시트 {접힘|절반|전체} · {n}곳」(공공시설 · 상점가), 상점가 없음 「… 가까운 상점가 없음, 가볼 만한 상점가 {n}곳」, 둘러보기 「… 축제 {n}건, 다른 상점가 {n}곳」.

## 9. 마커 레이어

탭이 소유한 레이어만 그린다(한 번에 하나, 시설 마커와 점포 마커를 함께 그리지 않는다).

| 탭 | 지도에 올라가는 것 | 클러스터 |
|---|---|---|
| 상점가 (현재 상점가 있음) | 점포 핀 = 필터 결과 전체(쪽 나누기와 무관) | 함 |
| 상점가 + 다른 상점가를 고른 동안 | 고른 상점가 핀 한 곳 + 구역 면 (점포 핀도 함께 있다 — 점포 레이어는 그대로) | 상점가 핀은 안 함 |
| 상점가 (현재 상점가 없음, `?district=none`) | 가까운 상점가 3곳 핀 (점포 핀 없음) | 안 함 |
| 공공시설 | 시설 핀 = 반경 · 유형 필터 결과 전체 | 안 함 |
| 둘러보기 | 없음 | — |

- 점포 클러스터(`MarkerClusterer`): 평균 중심, 최소 레벨 3, 구간 `[10, 100]` 으로 크기 3단(40 · 48 · 58px). 클러스터를 누르면 확대한다.
- 핀 크기 28×36, 모양은 같고 색만 다르다:

| 핀 | 색 토큰 |
|---|---|
| 점포 | `--pin-store` (잉크 회색) |
| 온누리 가맹 점포 | `--pin-store-onnuri` (teal) |
| AED / 대피소 | `--pin-aed`(red-500) / `--pin-shelter`(red-700) |
| 화장실 / 쉼터 | `--pin-toilet`(blue-600) / `--pin-rest`(teal-500) |
| 상점가 / 축제가 걸린 상점가 | `--pin-district`(브랜드 초록) / `--pin-festival`(호박) |
| 길찾기 도착지 | `--pin-dest` |
| 고른 핀 | `--pin-selected`(민트) + 1.12배 + 아래에서 번지는 물결(64px) |

- 고른 핀(`selectedId`)은 클러스터에서 꺼내 지도에 직접 올리고(숫자 뒤에 숨지 않게) 물결을 얹는다. 선택이 풀리면 원래 이미지 · 클러스터로 되돌린다.
- 기준점 앵커: 파란 점(18px + 후광) + 흰 말풍선(`anchorLabel`). 지도 생성 때 한 번 그린다.
- 구역 면(`areas`): 3점 이상 경로의 다각형, 선 2px(브랜드 초록 .9), 채움 .18, 마커 · 클러스터 아래(zIndex 1).
- 코스 레이어(S08): 30px 원 순번 버튼(`CustomOverlay`) + 기준점부터 순서대로 잇는 점선(`shortdash`, 4px). 고른 곳은 강조색(`--pin-course-active`) · 1.28배, 방문한 곳은 투명도 .45.
- 경로 레이어(S07): 성공 = 흰 밑선 10px + 파란 본선 6px + 꺾임 점 14px(고른 단계는 1.75배) + 도착 핀 / 폴백 = 회색 점선 4px.

## 11. 미정 · 한계

- 지도 위 필터 · 시트 수치는 토큰이 단일 출처이고, 코드가 읽는 지도 패딩 토큰은 `--map-pad-gap` 하나다.
- 도심 지점에서 유형별 건수 상한이 필요할 수 있으나 값은 실데이터 규모를 본 뒤 정한다(`facilities.js` 머리말) — 미정.
- 구역 면은 시연용 근사다(둔전: 점포 좌표 볼록 껍질, 나머지: 점포 수로 정한 반지름의 원). 실제 구역 좌표가 들어오면 `districts.js` 의 `zone` 만 바꾼다.
