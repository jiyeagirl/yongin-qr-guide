# 관리자 웹 기능 명세 (현재 상태) — 골목형 상점가 · 점포 · 엑셀 일괄 등록

공통 규격(목록 · 다이얼로그 · 검증 순서 · 저장 모델)은 `admin-overview.md` 5장.

## 근거 코드

| 파일 | 다루는 것 |
|---|---|
| `admin/pages/Districts.jsx` | M03 · M04 골목형 상점가 |
| `admin/pages/Stores.jsx` | M05 · M06 점포 |
| `admin/pages/BulkUploadModal.jsx` | 엑셀 일괄 등록 창 (점포 · 공공시설 공용) |
| `admin/data/fields.js` | `DISTRICT_FIELDS` · `STORE_FIELDS` · `deriveChip` · `CHIP_OPTIONS` · `ONNURI_TYPE_OPTIONS` · `V` |
| `admin/data/sources.js` | `DISTRICT_ROWS` · `STORE_ROWS`(기본값 채움) · `createdAtOf` |
| `admin/pages/useRecordEditor.js` · `RecordForm.jsx` · `EditorModal.jsx` · `useListState.js` | 공통 동작 |
| `design-systems/components/admin/{AddressField,CoordField,FileField}.jsx` | 주소 · 좌표 · 파일 |

## 1. 골목형 상점가 (M03 · M04) — `#/districts`

### 1-1. 목록

| 항목 | 내용 |
|---|---|
| 제목 · 개수 | 「골목형 상점가 정보 관리」 · 「{n}곳」 |
| 머리 단추 | [골목형 상점가 등록] → 등록 폼(다이얼로그) |
| 필터 | 구 고르개(「전체 구」 + 처인구 · 기흥구 · 수지구) → 검색창(「골목형 상점가명 검색」, 이름만 본다) |
| 열 | 골목형 상점가명(숨김이면 「숨김」 배지, 정렬) · 구(정렬) · 소재지(`area`, 없으면 `-`, 정렬) · 점포수(우측 정렬 「n곳」, 정렬) · 온누리(「n곳」, 정렬) · 노출 여부(토글) |
| 선택 · 일괄 | 체크박스 선택 → [노출] · [숨김] |
| 행 클릭 | 수정 창. 열 때 점포수 · 온누리 가맹 점포수 산출값을 폼에 얹는다 |
| 삭제 | 없음 |

**점포수 · 온누리 가맹 점포수 계산** (`countOf`): 그 상점가에 걸린 점포 행이 있으면 **노출 상태인 점포 수**와 그중 온누리 가맹 수를 센다(점포 정보 관리에서 노출을 끄면 줄어든다). 걸린 점포 행이 하나도 없는 상점가는 상점가 레코드의 `stores` · `onnuri` 값을 그대로 보여준다.

### 1-2. 등록 · 수정 다이얼로그

| 항목 | 내용 |
|---|---|
| 제목 | 「골목형 상점가 등록」 / 「골목형 상점가 수정」(크기 lg). 부제는 지금 입력된 상점가명 |
| 등록 기본값 | 구 = 목록에서 건 구 필터 값(「전체 구」면 처인구), 노출 여부 = 켜짐 |
| 등록 창에서 빼는 칸 | 점포수 · 온누리 가맹 점포수 (`id` 가 없는 값이면 두 칸을 항목표에서 거른다) |
| 저장 | `storeCount` · `onnuriCount` · `countManual` 은 버리고 나머지를 `upsert` |
| 저장 전 추가 검사 | 없음(`extraValidate` 없음) — 항목표 검사만 |

## 2. 점포 (M05 · M06) — `#/stores`

### 2-1. 목록

| 항목 | 내용 |
|---|---|
| 제목 · 개수 | 「점포 정보 관리」 · 「{n}곳」(천 단위 쉼표) |
| 머리 단추 | [점포 등록] (아이콘 upload) → 엑셀 일괄 등록 창(3장). 폼 등록은 없다 |
| 필터 | 소속 상점가(「전체 골목형 상점가」 + 32곳) · 대분류(「전체 대분류」 + 원천에서 뽑은 대분류) · 온누리(「온누리 전체」 / 「가맹」 / 「미가맹」) → 검색창(「상호명 검색」, 상호명만 본다) |
| 열 | 상호명(정렬) · 지점명(없으면 `-`) · 업종 칩(아이콘 + 이름, 손으로 고른 점포는 「수기」 배지, 정렬) · 상권업종대분류명(정렬) · 상권업종소분류명(없으면 `-`) · 온누리(가맹이면 배지 「지류」 「디지털」 「지류·디지털」 「가맹」(종류 없음), 아니면 `-`, 정렬) · 도로명주소(가운데 정렬, 정렬) · 조회(정렬) · 노출 여부(토글) |
| 선택 · 일괄 | 체크박스 → [노출] · [숨김] |
| 행 클릭 | 수정 창 |
| 삭제 | 없음 |

### 2-2. 수정 다이얼로그

| 항목 | 내용 |
|---|---|
| 제목 | 「점포 정보 수정」(크기 lg), 부제 상호명 |
| 새 점포 폼 | 없음 |
| 안내 상자 | 폼 맨 아래 「폐업을 확인했다면 [노출 여부]를 꺼 주세요.」 |
| 주소 선택 | 주소 · 위도 · 경도 세 값이 함께 들어온다 |
| 좌표 | 주소 바로 아래 지도 칸(`CoordField`, 슬롯) — 핀 끌기로 수정, 6자리로 반올림 |
| 저장 | `upsert`. 이력 라벨 「점포」. 추가 검사 없음 |

**칸끼리 움직이는 규칙** (`Stores.jsx` `setField`)

| 바뀐 칸 | 결과 |
|---|---|
| 표시 업종 칩을 직접 고름 | 칩을 바꾸고 `chipManual = true`(레코드에 저장). 이후 분류를 고쳐도 칩이 따라가지 않는다 |
| 대분류 · 중분류 · 소분류를 고침 | `chipManual` 이 아니면 `deriveChip(값)` 으로 칩을 다시 산출해 채운다 |
| 온누리 상품권 종류를 고름 | 선택이 하나라도 있으면 가맹여부가 켜지고, 모두 풀면 꺼진다 |
| 온누리 가맹여부를 끔 | 상품권 종류를 비운다 |
| 온누리 가맹여부를 켬 | 종류는 자동으로 채우지 않는다(비어 있으면 저장이 막힌다) |

**업종 칩 자동 산출 `deriveChip`** (대·중·소분류명은 앞뒤 공백을 턴 뒤 비교; 위에서 아래로 처음 맞는 줄)

| 조건 | 칩 |
|---|---|
| 대분류 = 「음식」이고 중분류에 `비알코올`·`커피`·`음료` 포함 | 카페/디저트(`cafe`) |
| 대분류 = 「음식」이고 (중분류+소분류)에 `제과`·`빵`·`도넛`·`디저트`·`빙수`·`아이스크림`·`커피` 포함 | 카페/디저트 |
| 대분류 = 「음식」 그 밖 | 음식(`food`) |
| 대분류에 `소매`·`도매`·`유통` 포함 + (중+소)에 `서점`·`서적` | 여가/문화(`culture`) |
| 〃 + (중+소)에 `약국`·`의약` | 생활/편의(`life`) |
| 〃 그 밖 | 쇼핑(`shop`) |
| 대분류에 `수리`·`개인`·`생활서비스` 또는 `보건`·`의료` | 생활/편의 |
| 대분류에 `교육`·`학문` | 교육(`edu`) |
| 대분류에 `여가`·`스포츠`·`예술` | 여가/문화 |
| 나머지(부동산 · 시설관리 및 임대 · 과학 및 기술 · 숙박 등) | 기타(`etc`) |

칩 선택지(저장값 → 화면 이름): `food` 음식 · `cafe` 카페/디저트 · `shop` 쇼핑 · `life` 생활/편의 · `edu` 교육 · `culture` 여가/문화 · `etc` 기타.

## 3. 엑셀 일괄 등록 창 (`BulkUploadModal`)

점포(M05)의 [점포 등록]과 공공시설(M11)의 [공공시설 등록]이 같은 창을 연다. 골목형 상점가는 폼 등록이라 이 창을 쓰지 않는다.

| 항목 | 점포 | 공공시설 |
|---|---|---|
| 창 제목 | 점포 일괄 등록 | 공공시설 일괄 등록 |
| 설명 줄 | 엑셀 파일을 통해 일괄 등록 가능합니다. | 〃 |
| 먼저 고르는 칸 | **소속 골목형 상점가** (필수, 첫 줄 「— 선택 —」 + 32곳) | **시설 유형** (필수, 첫 줄 「— 선택 —」 + AED · 대피소 · 쉼터 · 화장실) |
| 칸 아래 한 줄 | 업로드한 파일의 모든 점포가 현재 선택한 상점가로 등록됩니다. | 업로드한 파일의 모든 시설이 현재 선택한 유형으로 등록됩니다. |
| 기본값 | 목록의 소속 필터 값 (「전체」면 비어 있음) | 목록의 유형 필터 값 (「전체 유형」이면 비어 있음) |
| 잠금 문장 | 소속 골목형 상점가를 먼저 선택해주세요. | 시설 유형을 먼저 선택해주세요. |

**창 동작 (공통)**

| 순서 | 동작 |
|---|---|
| 파일 칸 | 위 칸을 고르기 전에는 잠긴다(흐려지고, 눌러도 끌어다 놓아도 받지 않음). 잠금 문장이 규칙 줄 자리에 선다 |
| 받는 파일 | `.xlsx` · `.xls`, 최대 10MB. 어긋나면 이유를 칸에 적고 이미 고른 파일은 유지 |
| 고른 뒤 | 파일 이름 · 크기 · [파일 바꾸기] (제거 단추 없음) |
| [업로드] | 흐리지 않고 눌린다. 확인 순서: ① 잠금 문장이 있으면 그 문장을 오류로(파일 칸이 붉어짐) ② 파일이 없으면 「올릴 엑셀 파일을 먼저 골라 주세요.」 ③ 통과하면 창을 닫는다 |
