# 관리자 웹 기능 명세 (현재 상태) — 개요 · 공통

> 이 문서는 **현재 코드가 하는 일**만 적는다. 코드에서 확인하지 못한 것은 적지 않았고, 코드가 「미정」이라고 둔 것은 그대로 「미정」이라 적었다.
> 화면별 상세는 같은 폴더의 `admin-districts-stores.md` · `admin-festivals-courses.md` · `admin-facilities-qr-reports.md`.

## 근거 코드

| 파일 | 다루는 것 |
|---|---|
| `admin/index.html` | 부트스트랩(번들 / 로더), 접속 주소 `/admin/` |
| `admin/AdminApp.jsx` | 로그인 게이트, 메뉴(NAV), 화면 매핑, 내비 배지, 토스트, 상단 띠 고지 |
| `admin/router.js` | 해시 라우터 |

| `admin/data/fields.js` | 입력 항목표(폼의 유일한 출처) · 검증 규칙 · `validate()` |

| `admin/pages/*` (Login, Dashboard, Districts, Stores, Festivals, Courses, Facilities, QrPoints, Reports, Accounts, BulkUploadModal, EditorModal, RecordForm, useRecordEditor, useListState, ImageField) | 화면 |
| `design-systems/components/admin/*` (AdminShell, FormGrid, AddressField, CoordField, Repeater, AssetPicker, OptionPicker, FileField) | 공용 입력 부품 |

## 1. 범위

### 화면이 하는 일

- 골목형 상점가 · 점포 · 축제(프로그램·부스) · 골목 한바퀴 코스 · 공공시설 · QR 지점의 **개별 건 조회 · 수정 · 신규 등록**
  - 신규 등록은 화면마다 다르다: 폼 등록(상점가 · 축제 · 코스 · QR 지점 · 계정), 엑셀 파일 받기(점포 · 공공시설). 오류신고는 등록이 없다.
- 목록에서 **노출 여부 / 사용 여부** 토글(한 줄) 및 일괄 노출·숨김(선택한 여러 줄)
- 오류신고의 처리 상태 · 담당자 · 내부 메모 기록
- 계정 등록 · 수정 · 사용 여부, 비밀번호 초기화 요청 처리 (최종 관리자 전용)
- 대시보드 조회(요약 수치, 차트, 상점가별 둘러보기 매장 미리보기)
- 모든 등록 · 수정 · 일괄 수정 · (코드상) 삭제를 변경 이력으로 기록 (`store.js` `log`)

### 화면이 하지 않는 일 (코드에 해당 기능이 없다)

| 없는 것 | 코드 상태 |
|---|---|
| **삭제** | 화면 열여섯 어디에도 삭제 단추 · 「관리」 열 · 삭제 확인 창이 없다. `useRecordEditor` 에 삭제 기계가 없다. `store.js` 의 `remove`·`removeRows` 함수는 남아 있으나 부르는 화면이 없다 |
| 데이터 일괄 적재 · 매칭 · 갱신 · 검수 | 해당 화면 없음. 엑셀 창은 파일을 받는 데까지만 한다(점포 · 공공시설 문서 참조) |
| 서비스 운영 설정(안내 범위 · 배너 기준 · 확대 단계 등) | 화면 없음. 값은 시민용 코드(`config.js` · `facilities.js`)에 있다 |
| 데이터 기준일 화면 | 화면 없음 |
| 변경 이력 열람 | 기록만 쌓고(`readHistory`) 읽는 화면 없음 |
| 오류신고 회신 | 회신처 · 회신 내용 칸 없음 |
| 이미지 업로드 | 폼 어디에도 업로드 칸 없음 (`ImageField.jsx` 는 있으나 부르는 화면 없음). 조아용 이미지는 사전 등록 8종 중 선택 |
| QR 이미지 생성 · 진입 URL 표시 | 없음 (`qrEntryUrl()` 은 정의만 있고 부르는 곳 없음) |
| QR 지점의 「연계 축제」(`festival_id`) 칸 | 폼에 칸 없음. 조건부 필수 규칙(`isPamphlet`)만 항목표에 걸려 있다 |
| 관리자 → 시민용 화면 반영 | 서버 없음. 고친 값은 이 탭의 `sessionStorage` 에만 남는다 |

## 2. 진입 · 라우팅

| 항목 | 내용 |
|---|---|
| 접속 주소 | `/admin/` (`admin/index.html`) |
| 로딩 | `bundle.js` 가 있으면(HEAD 요청 성공) 번들만 받는다. 없거나 `?dev=1` 이면 Babel 로더로 `.jsx` 원본을 변환해 띄운다 |
| 검색 노출 | `<meta name="robots" content="noindex, nofollow">` |
| 라우팅 | 해시 라우터 `#/<화면키>`. 첫 구간만 읽는다(`#/stores/dj-004` 도 `stores`). `go(page)` 는 `pushState`, `replace(page)` 는 `replaceState` |
| 화면 키 | `dashboard · districts · stores · festivals · courses · facilities · qr · reports · accounts` (`data/account.js` `ALL_PAGES` 가 유일한 목록) |
| 로그인 전 | 셸을 세우지 않고 로그인 화면만 그린다 |
| 없는 주소 · 권한 없는 주소 | 첫 번째 메뉴 화면(대시보드)으로 `replace` 한다 (`can(account, page)` 가 거짓이면) |
| 좁은 화면 | 폭 1024px(`--admin-min`) 미만이면 `AdminShell` 이 화면 대신 안내 문구를 그린다. 본문 최대 폭 `--admin-max` 1600px, 내비 폭 `--admin-nav-w` 264px |

## 5. 공통 UI 규격

### 5-1. 목록 화면 (`useListState` · `DataTable` · `Toolbar`)

| 항목 | 규칙 |
|---|---|
| 쪽 크기 | 20행 고정(고르개 없음). 아래에 `Pagination` |
| 정렬 | 열 머리 클릭(열별로 `sortable`) |
| 검색 | 한 칸만 본다. 2자 미만이면 거르지 않고(`MIN_SEARCH`=2) 「2자 이상 입력하면 검색합니다.」를 보인다. 일치는 부분 문자열(`includes`) |
| 필터 · 검색이 바뀌면 | 첫 쪽으로 돌아가고 선택을 비운다 |
| 선택(체크박스) | 점포 · 공공시설 · 골목형 상점가 · 축제 · 코스 · QR 지점 목록에 있다. 선택하면 도구줄 오른쪽에 「n건 선택」과 단추가 선다 |
| 일괄 처리 | 위 목록들은 [노출] · [숨김], QR 지점은 [사용] · [미사용]. 변경 후 토스트 「n건을 노출|숨김|사용|미사용으로 바꿨습니다.」, 선택 해제. 이력에는 「일괄 수정」 한 줄 |
| 행 클릭 | 수정 다이얼로그를 연다 (오류신고는 처리 다이얼로그, 요청 탭은 계정 수정 창) |
| 노출/사용 토글 | 표에서 바로 누른다(`patch` → 이력 「수정」). 토글 옆에 상태 글자를 적지 않는다 |
| 빈 목록 | 제목 한 줄만 (예: 「조건에 맞는 점포가 없습니다.」) |
| 열 이름 | 머리줄에는 열 이름만 적는다 |
| 값이 없을 때 | `-`(`EMPTY_MARK`) |

### 5-2. 등록 · 수정 다이얼로그 (`useRecordEditor` · `EditorModal` · `RecordForm`)

| 항목 | 규칙 |
|---|---|
| 폼 구성 | `fields.js` 의 항목표(배열)를 `RecordForm` 이 줄마다 입력 칸으로 그린다. 2열 격자, `span: 2` 면 한 줄 전체 |
| 열릴 때 | 수정은 행을 **복사**해 연다(취소하면 목록이 바뀌지 않는다). 등록은 화면의 `initial()` 값으로 연다 |
| 저장 버튼 | [저장]. 검증(`validate`)에 걸리면 **창을 닫지 않고** 해당 칸에 오류를 붙이고 토스트 「입력을 확인해 주세요.」 |
| 오류가 사라지는 때 | 그 칸을 고치는 순간(`set` / `setMany`). 좌표 칸은 좌표가 생기면 스스로 사라진다 |
| 저장 성공 | 토스트(등록 「{라벨}을(를) 등록했습니다.」 / 수정 「{라벨} 정보를 저장했습니다.」)를 띄우고 창을 닫는다. 토스트는 2.6초 뒤 사라진다 |
| 이탈 확인 | 값이 처음과 달라졌을 때만, [취소] · X · ESC 로 닫으려 하면 「저장하지 않고 닫을까요?」(「고친 내용이 사라집니다.」 · [계속 편집] / [닫기]). 고친 것이 없으면 그냥 닫는다. 확인 창은 폼을 닫으면서 대신 띄운다(겹치지 않는다) |
| 칸 아래 한 줄 | 오류가 있으면 오류만, 없으면 항목의 `hint` 만 |
| 칸 안 흐린 글씨 | 입력 칸(select · switch · date 제외)에 「예) {example} ({range})」, 예시가 없으면 범위만 |
| 필수 배지 | 칸 이름 옆에 **필수 / 선택 / 조건부 / 자동** 글자 배지(`RequiredBadge`) |
| 자동(⚙) 칸 | 입력 칸이 아니라 점선 테두리의 읽기 전용 상자로 그린다(값 + 단위, 없으면 `-`) |
| 가부 항목 | 스위치 하나. 저장값은 불리언 |
| 단위 | `unit`(칸, 명, 곳, 회)은 칸 밖에 글자로 붙는다. 저장값에 들어가지 않는다 |
| 빈 항목 안내 문단 | 폼 아래 공통 안내 문단은 없다(화면이 `note` 로 넘길 때만) |

**항목표 한 줄이 가진 속성** (`fields.js` 머리말): `key`(데이터 필드명) · `spec`(서버 컬럼명, 매핑용) · `label` · `required`(`true`/`false`/`"cond"`/`"auto"`) · `when`(조건부 조건) · `requiredMsg` · `type`(`text` `number` `date` `textarea` `select` `multiselect` `switch` `readonly` `address` `coord` `picker` `password`) · `options` · `range`(화면에 적는 문구) · `minLength` · `maxLength` · `min` · `max` · `pattern` · `example` · `hint` · `span` · `unit` · `rows` · `reveal`.

**저장 검사 `validate(fields, values, extra)` 의 순서** (한 칸에서 처음 걸린 것 하나만 적는다):

1. `required: "auto"` · `type: "readonly"` 는 건너뛴다.
2. `coord` 는 필수일 때 `lat`·`lng` 가 유한한 숫자가 아니면 「도로명주소를 선택하거나 지도에서 위치를 지정해 주세요.」(오류는 `coord` 칸에 붙는다). 범위 검사는 하지 않는다.
3. `switch` 는 항상 통과.
4. 비어 있으면(multiselect 는 빈 배열) 필수일 때만 오류: `requiredMsg` 가 있으면 그것, 없으면 조건부는 「이 조건에서는 필수 항목입니다.」, 아니면 「필수 항목입니다.」. 비어 있으면 아래 검사를 하지 않는다.
5. `minLength` 미만 「N자 이상 적습니다.」 → `maxLength` 초과 「N자까지 적을 수 있습니다.」 → `pattern` 불일치(패턴의 `msg`) → 숫자 칸: 숫자 아님 「숫자로 적습니다.」, `min` 미만 「N 이상이어야 합니다.」, `max` 초과 「N 이하여야 합니다.」
6. 마지막에 화면이 넘긴 `extraValidate(values)` 결과를 합친다 — **이미 걸린 칸은 덮지 않는다**.

문자열은 `trim` 한 값으로 검사한다.

**1:N 목록의 필수 칸** (`missingInRows`): 필수 열이 빈 첫 줄만 「{n}번째 줄의 {열 이름들}을/를 채워 주세요.」(열 이름은 ` · ` 로 잇고 마지막 낱말 받침에 따라 을/를을 고른다. 예: 「2번째 줄의 종료 일시 · 프로그램명을 채워 주세요.」). `daytime` 칸은 `YYYY-MM-DDTHH:mm` 전체 형식이어야 「채워진 것」으로 본다.

| V-07 | 기간 | 축제: 종료일 < 시작일이면 종료일 칸에 「종료일은 시작일과 같거나 이후여야 합니다.」(같은 날 허용). 프로그램 · 부스 줄: 종료 일시 < 시작 일시이면 「{n}번째 줄의 종료 일시가 시작 일시보다 빠릅니다.」 | `Festivals.jsx` `extraValidate` |

**그 밖에 코드에 있는 검사**

| 대상 | 규칙 |
|---|---|
| 계정 아이디 | `V.loginId` (7-5) |
| 계정 비밀번호 | `checkPassword` (7-5) |
| `V.yearMonth` | `^\d{4}\.(0[1-9]|1[0-2])$` 정의만 있고 쓰는 곳 없음 |
| 골목형 상점가명 | 길이 2~40자. 「전역 유일」이라고 범위 문구에 적혀 있으나 중복 검사 코드는 없다 |
| QR ID | 목록에서 고르는 값이라 형식 검사 없음. 이미 다른 지점에 걸린 ID 는 「이미 다른 지점에 매칭된 QR ID 입니다.」로 막는다(`QrPoints.jsx`) |
| 코스 | 4곳 모두 선택 · 같은 점포 중복 불가 (`Courses.jsx`) |

## 9. 공용 입력 부품 요약

| 부품 | 동작 |
|---|---|
| `OptionPicker` | 검색해서 고르는 칸. 누르거나 ↓ · Enter · 글자 입력으로 열린다(포커스만으로는 열리지 않음). 목록은 열 줄까지 보이고 `disabled` + `note` 항목은 흐리게 보이며 고를 수 없다. QR ID · 코스 점포 칸이 쓴다 |
| `FileField` | 끌어다 놓거나 눌러서 엑셀 한 개를 고른다. `accept=".xlsx,.xls"`, 최대 10MB. 규칙에 어긋나면 이유를 적되 이미 고른 파일은 지우지 않는다(「.xlsx · .xls 파일만 올릴 수 있습니다.」 / 「파일이 10.0MB를 넘습니다. (n)」). `blocked` 문장이 있으면 칸이 잠기고 그 문장이 규칙 줄 자리에 선다 |
| `AssetPicker` | 조아용 이미지 썸네일 격자(8종), 다른 축제가 쓰는 그림에 「n건 사용 중」 배지, 겹치는 그림을 고르면 이름 줄에 「이미 다른 축제에서 사용 중인 이미지입니다. 다른 이미지를 선택해주세요.」(막지 않는다) |
| `Repeater` | 1:N 편집기 (festivals-courses 문서) |
