# 시민용 — 공공시설 탭 (현재 상태)

코드가 기준이다. 정해지지 않은 것은 「미정」으로 둔다.

## 근거 코드

- `screens/main/MainApp.jsx` — 시설 필터 · 반경 · 폴백 · 경고 계산 · 시트 · 지도 · 카드
- `screens/main/FacilitySheet.jsx` — 시트 내용(목록)
- `screens/main/data/facilities.js` — 더미 시설 · `RADIUS_STEPS` · `NEAR_ENOUGH`
- `screens/main/config.js` — `FACILITY_PAGE_SIZE`, `TAB_MAP_LEVEL`
- `design-systems/components/facility/FacilitySummary.jsx` — 시트 헤더 개수 줄 · 원거리 안내 말풍선
- `design-systems/components/core/FacilityIcon.jsx` — `SAFETY`, `CONVENIENCE`, `FACILITY_TYPES`
- `design-systems/components/core/FilterBar.jsx` — 칩 규칙
- 방향 근거: `docs/direction_v2_rules.md` 4장 · 8장 (공공시설 탭의 기능 · 안전 안내는 수정 없음)

## 1. 위치

- 탭바 첫 칸(아이콘 `life-buoy`, 이름 「공공시설」). 진입 시 처음 선택되는 탭은 아니다.
- 해시 없이 셸의 탭 상태이며, 시설 상세는 `#/facility/:id`(S05), 길찾기는 `#/route/facility/:id`(S07) 오버레이다.
- 지도 인스턴스는 상점가 탭과 하나를 공유한다. 한 번에 한 레이어만 그린다 — 이 탭에서는 시설 핀만.

## 2. 데이터

| 항목 | 값 |
|---|---|
| 유형 | `aed` · `shelter`(대피소) · `rest`(쉼터) · `toilet`(화장실) — `FACILITY_TYPES` 순서(칩 · 개수 줄 기준) |
| 안전시설 | `SAFETY` = AED · 대피소 · 쉼터. 편의시설 `CONVENIENCE` = 화장실 |
| 더미 시설 | 22곳(AED 7 · 대피소 3 · 화장실 7 · 쉼터 5). id `fc-001`~ 거리순, 모두 `ANCHOR` 기준 (거리 · 방위 → 좌표 계산) |
| 이름 | 화장실 · 쉼터는 데이터의 `name`. AED · 대피소는 이름 항목이 없어 도로명 + 건물번호 + 유형(「둔전로 42 AED」)으로 만든다 (`facilityName`) |
| 거리 | `ANCHOR` 기준 직선거리(m). 목록에 도보 시간 표기(`WALK_M_PER_MIN` = 67) |
| 반경별 곳수 | 2km 17 / 3km 20 / 4km 22 |

## 3. 안내 반경 (U-FC-08)

| 항목 | 값 |
|---|---|
| 칸 | 2 · 3 · 4km (`RADIUS_STEPS` = 2000/3000/4000) |
| 기본값 | 2km (`RADIUS_DEFAULT`) |
| 고르는 자리 | 시트 제목 줄 오른쪽 끝 `InlineSelect`, 단추 글 「반경 2km」 · 목록 「2km」「3km」「4km」(소수점 없음). 전체 스냅에서도 보인다 |
| 효과 | 목록의 곳수 · 핀 · 개수만 바꾼다. 카메라 · 축척은 움직이지 않는다. 반경 원은 그리지 않는다 |
| 유지 | 탭을 옮겨도 값이 남는다. 카메라는 탭마다 기본 자리(`ANCHOR` + 레벨 4)로 돌아간다 |
| 쪽 | 반경이 바뀌면 1쪽으로 |

- 유형별로 반경 안 시설을 거른다(`dist <= radius`).
- **폴백**: 어떤 유형이 반경 안에 0곳이면 반경을 무시하고 그 유형의 최근접 2곳을 대신 싣는다. 빈 결과 화면이 나오지 않도록 하는 규칙이다.

## 4. 시트 제목 · 칩

| 요소 | 규칙 |
|---|---|
| 시트 제목 | 고른 유형이 0개이거나 4개 전부면 「주변 공공시설」. 그 사이는 「주변 AED · 화장실」처럼 고른 유형 이름을 `FACILITY_TYPES` 순서로 ` · ` 로 잇는다 |
| 지도 위 칩 | [전체] + 유형 4종(`FACILITY_TYPES` 순서). 검색창 없음. 여럿 고르기, 빈 배열이 전체. 개수는 반경 · 폴백을 적용한 곳수. 0건인 칩은 숨긴다 |
| 칩 색 | 선택 상태를 색으로 쓰므로 안전시설 적색 강조를 끈다 (`emphasis={false}`) |
| 정렬 · 검색 | 없다. 거리순 하나뿐 |

## 5. 시트 헤더 — 개수 줄과 원거리 안내 (U-FC-09)

헤더 개수 줄(`FacilitySummary`)은 접힘 스냅에서도 보인다.

| 요소 | 규칙 |
|---|---|
| 기준 문구 | 「QR 스캔 지점 기준 직선거리 · 가까운 순」 |
| 개수 | 안전시설(`SAFETY`: AED · 대피소 · 쉼터)만 센다. 곳수 0이어도 경고가 걸린 유형은 보인다. 화장실 개수는 여기 없다 |
| 개수의 값 | 반경 · 폴백 적용 후 유형별 곳수 |

**원거리 안내 규칙** (`MainApp.facilityNotices`)

| 항목 | 값 |
|---|---|
| 기준 | `NEAR_ENOUGH` = 1000m. 사용자에게 노출하지 않는다 |
| 대상 | 유형을 고르지 않았으면 안전시설(AED · 대피소 · 쉼터)만, 고른 유형이 있으면 그 유형만 (화장실을 골랐으면 화장실도) |
| 조건 | 대상 유형의 최근접(반경 · 폴백 적용 후 맨 앞)이 1000m 를 넘으면 경고 |
| 반경과의 관계 | 반경을 몇으로 두었든 최근접이 1km 밖이면 경고가 뜬다 |
| 거리 표기 | 1000m 이상은 「N.Nkm」(소수 한 자리), 미만은 「Nm」 |

**표시 방식**

- 경고가 걸린 유형의 개수 아이콘에 주의 배지가 붙고, 줄 전체에 걸린 말풍선 하나가 열린다. 꼬리가 경고 유형 아이콘을 가리킨다.
- 문장은 하나다: 「가까운 곳에 {유형, 유형}이/가 없습니다. 가장 가까운 {유형}은/는 {거리}, … 떨어져 있습니다.」 나열 차례는 `SAFETY` 순(AED · 대피소 · 쉼터), 조사는 받침을 따른다. 하나만 걸리면 쉼표 없이 한 유형.
- 경고가 새로 생기면(칩 · 반경이 바뀌어 경고 묶음이 달라지면) 말풍선이 저절로 열린다. 닫으면 다시 열리지 않는다. 다시 여는 것은 아이콘과 주의 배지를 눌렀을 때뿐이고, 눌러 열면 닫은 기록을 지운다.
- 닫은 기록(`warnDismissed`)은 셸이 들고 있다 — 탭을 옮겼다 와도 유지된다. 값은 경고 묶음 문자열이며, 경고가 달라지면 새 경고로 친다.
- 더미 기준 기본(2km) 화면: 대피소 최근접 1400m 라 대피소 경고가 뜬다. AED(120m) · 쉼터(90m)는 경고 없음.

## 6. 목록 (`FacilitySheet`)

| 요소 | 규칙 |
|---|---|
| 순서 | 안전시설 묶음(AED · 대피소 · 쉼터)이 먼저, 편의시설(화장실) 다음. 각 묶음 안은 거리순 |
| 머리말 | 「안전시설」 / 「편의시설」은 현재 쪽에 두 묶음이 다 있을 때만. 잘린 자리에 걸친 묶음은 다음 쪽에서 머리말을 다시 단다 |
| 쪽 나누기 | 10곳(`FACILITY_PAGE_SIZE`). 묶음별이 아니라 위 순서대로 편 한 줄을 자른다. 「{N}곳 중 a–b」 + `Pagination`(라벨 「공공시설 목록 쪽 넘기기」). 범위를 넘은 쪽은 마지막 쪽으로 맞춘다. 유형 · 반경이 바뀌면 1쪽 |
| 쪽과 지도 | 지도 핀은 쪽을 따르지 않는다 — 필터 · 반경에 걸린 전부를 찍는다 |
| 행 | `FacilityRow`(이름 + 배지 / 거리 · 도보 / 위치 · 운영시간). 선택된 시설은 강조 |
| 행을 누르면 | 상세로 가지 않고 지도에 핀을 켜고 미리보기 카드를 띄운다 (마커를 누른 것과 같다) |
| 빈 결과 | `Notice` 「조건에 맞는 시설이 없습니다.」 (폴백 · 0건 칩 숨김으로 사실상 나오지 않는다) |
| 고지 | 「안내 정보는 참고용입니다. 응급 상황에는 119 등 공식 채널로 연락해 주세요.」 |
| 기준일 | 목록에는 적지 않는다. 유형별 기준일은 시설 상세가 그 유형 하나만 적는다 |
| 스크롤 | 유형 · 반경 · 쪽이 바뀌면 맨 위로 (`scrollKey`) |

## 7. 지도 · 미리보기 카드

| 항목 | 규칙 |
|---|---|
| 핀 | `facilityRows`(필터 + 반경 + 폴백 적용 결과 전체) |
| 기본 줌 | 탭 전환 시 `ANCHOR` + 레벨 4 (`TAB_MAP_LEVEL.facility`) |
| 필터 바 | 칩 줄만(검색 없음) — 상점가 탭보다 한 줄 낮다. 지도 패딩은 실측값 |
| 카드 | 시설 아이콘 · 이름 · 유형 이름(`FACILITY_LABELS`) · 위치 문구(`place` 있으면 그것, 없으면 `addr`) · 거리 |
| 카드 단추 | [길찾기] → `#/route/facility/:id`, [상세 보기] → `#/facility/:id` |
| 카드 + 시트 | 카드가 뜨면 시트를 접힘으로 내리고, 카드 [×] 에서 내리기 전 스냅으로 돌아간다 (공통 규칙은 `citizen-district-tab.md` 3-2) |
| [스캔 위치로] | 상점가 탭과 같은 단추 · 같은 조건 |
| 시설 선택 | 탭을 옮기면 선택과 스냅(절반)이 초기화된다 |

## 8. 코치마크 · 문구에서의 위치

- 코치마크 첫 걸음 「내 주변 시설을 확인해요」: 「QR을 찍은 곳에서 가까운 AED, 대피소, 쉼터, 화장실을 알려드려요.」 (탭바 첫 칸을 밝힌다. 자세한 규칙은 `citizen-entry-qr.md` 8장)
- 상점가 없음 안내(S03-E)의 글자 링크 [공공시설 탭으로]가 이 탭으로 전환한다.
