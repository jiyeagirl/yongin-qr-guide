## 2. 시트 (S03) — 축제 배너 + 가게 목록 (2026-10-19 되돌림)

> **홈형(인기 매장 · 코스 · [전체매장] · 주변 상점가)이었다가 2026-10-19 사용자 요청으로 가게 목록형으로 되돌렸다.** 아래 표 중 3~5행(인기 매장 · 코스 · 전체매장 · 주변 상점가)은 **지금 시트에 없다** — 인기 매장 · 코스 · 용인 골목형 상점가는 둘러보기 탭(S04)이 맡는다. 시트는 축제 배너(조아용) → 목록 제어(결과 수 · 온누리 칩 · 정렬 거리순/인기순) → 점포 목록 20곳씩(`StoreRow`) → 「N곳 중 a–b」 + 쪽 나누기 → 고지다. 지도 위 검색창과 업종 칩은 이 목록을 바로 거른다(Enter 로 S15 를 열지 않는다). 점포 행을 누르면 지도에서 켠다(`pickOnMap`).

시트 제목은 현재 상점가 이름(`DISTRICT.name` = 「동백이음길 골목형상점가」). 제목 줄 오른쪽에 `DistrictSummary`(소재지 `area`: 「동백중앙로 358-19 일원」)가 선다. 위에서 아래로:

| 순서 | 섹션 | 내용 · 규칙 |
|---|---|---|
| 1 | 우리 상점가 축제 배너 | `CURRENT_FESTIVAL`(현재 상점가의 축제, 상태가 종료면 없음). 눌러 `#/festival/{id}`. [×] 로 닫으면 자리째 사라진다. 닫은 축제 id 를 셸이 기억한다 — 탭을 옮겨도 유지, 다른 축제로 바뀌면 다시 보인다 |
| 2 | 인기 매장 | `POPULAR` — 조회수 상위 8곳(`DISCOVER_PICK`, `visible:false` 제외). 부제는 상점가 이름. 1위 노트 「이번 주 조회 1위」, 나머지 「조회 N회」. 눌러 지도에 핀을 켠다 (아래 4장) |
| 3 | 골목 한바퀴 코스 추천 | `d.courses` 가로 스크롤 카드. 눌러 `#/course/{id}`. 상점 QR 진입이면 그 가게 둘레 코스(`coursesFrom`), 아니면 `COURSES`(먹자골목 · 온누리 알뜰 · 동네 상점 둘러보기 중 들르는 곳이 3곳 이상인 것) |
| 4 | [동백이음길 골목형 상점가 전체매장 >] | 회색 알약(`variant=subtle`), 글은 `shortName(district)` + 「 전체매장」. 눌러 S15 (`#/stores`) |
| 5 | 주변 골목형 상점가 | 거리순 가까운 3곳(`HOME_DISTRICT_PREVIEW`, 현재 상점가 제외). 줄 → 지도 이동 (5장). 목록 아래 [주변 골목형 상점가 전체보기 >] 알약 → S13 (`#/districts`) |
| 6 | 고지 | 「점포 정보 2026.03. 기준. 안내 정보는 참고용입니다.」(`STORE_AS_OF`). 119 문구 없음 |

- 시트에는 가게 목록 · 업종 칩 · 온누리 칩 · 정렬 · 쪽 나누기가 없다. 그것들은 S15 에 있다.
- 시트는 3단 스냅(접힘 / 절반 / 전체)이고 진입 시 절반이다. 높이 비율은 `tokens/layers.css` 가 단일 출처다. 전체 스냅이면 헤더에 [지도] 단추가 서서 절반으로 돌아간다.
- 점포는 동백이음길의 실제 점포 227곳(`dongbaekStores.js`)이다. 업종(점포명 추정) · 인기(조회수) · 코스는 시연용 생성값이다 (`current.js`). 층 · 상인회 정회원 · 온누리 가맹은 받은 표의 값이다.

## 3. 지도 영역 (상점가 탭)

| 항목 | 규칙 |
|---|---|
| 지도 | 탭을 옮겨도 다시 만들지 않는다. 둘러보기 탭에서는 `display:none` 으로 감춘다 |
| 점포 핀 | `storeRows`(필터 결과 전체, 쪽 나누기와 무관)를 찍는다. 상점가 없음(S03-E)에서는 찍지 않는다 |
| 필터 바(지도 위) | 검색창 + 업종 칩 `d.chips`(7종 + 앞의 [전체]). 칩은 핀을 거른다 |
| 상점가를 골라 지도가 넘어간 동안 | 업종 칩을 내린다(검색창은 남김). 카드를 닫으면 칩이 돌아온다 |
| 검색창 | 누르면(포커스) 또는 Enter 를 치면 S15 를 연다. 입력은 S15 의 검색창에서 받으며, 열린 직후 거기로 포커스를 옮긴다 (`flushSync` + `focus`) |
| 기본 줌 | 탭 전환 시 카메라를 `ANCHOR` + 레벨 4 로 되돌린다 (`TAB_MAP_LEVEL.district`) |
| [스캔 위치로] | 지도 우하단 플로팅. 앵커가 지도 칸 밖일 때만 뜨고 전체 스냅에서는 숨는다. 누르면 선택 해제 · 시트 접힘 · 지도 리셋 · 토스트 「QR스캔 위치로 이동했습니다」 |

### 3-1. 상점가 구역 면

- 다른 상점가 줄 · S13 줄을 눌러 지도가 그 상점가로 넘어갔을 때만 핀과 함께 면(`zone`)을 그린다. 상점가 탭의 평소 화면(현재 상점가)에는 그리지 않는다.
- **건물 핀 · 건물 시트** (2026-10-30, 사용자 요청): 지도는 가게 대신 건물마다 핀 하나(건물명 + 조건에 걸린 가게 수). 핀을 누르면 시트 제목이 건물명이 되고 내용이 **층별 목록**(층 제목은 「1F」 · 「6·7F」 · 「B1F」로 적는다 — 자료는 「1층」 그대로; 제목 오른쪽에는 아무것도 두지 않는다 — 온누리 칩을 잠시 두었다가 사용자 요청으로 뺐다. 1층부터 위로, 「2·3층」처럼 여러 층인 가게는 그 아래층 묶음 뒤, 지하는 맨 뒤)이 된다. 줄은 업종 아이콘 · 상호 · 온누리 배지 · 업종이고(정회원 표시는 줄에 두지 않는다 — 상세의 배지가 말한다), 누르면 가게 상세로 간다. [닫기] 단추는 없다 — **같은 핀을 다시 누르거나 지도 빈 곳을 누르면** 상점가 시트로 돌아간다(탭을 바꾸거나 [스캔 위치로]를 눌러도). 업종 칩 · 검색어 · 온누리 조건이 그대로 걸린다(`BuildingSheet.jsx`).
- `zone`: 현재 상점가(동백이음길)는 점포 좌표의 볼록 껍질, 나머지 31곳은 대표 좌표 중심의 원(반지름 = `min(320, max(70, 12 × √점포수))` m). 구역 경계 자료가 없어 대략의 시연값이다. 실제 좌표가 들어오면 `districts.js` 의 `zone` 만 바꾼다.
- 지도에 올라가는 상점가 핀은 고른 한 곳뿐이다. (상점가 없음 상태는 예외 — 5장.)

### 3-2. 미리보기 카드

| 대상 | 카드 | 단추 |
|---|---|---|
| 점포 | 이름 · 업종 · 주소 · 거리 | [길찾기] → `#/route/store/:id`, [상세 보기] → `#/store/:id` |
| 상점가 | 사진 자리 · 구 · 「점포 N곳, 온누리 N곳」 · 거리 | [상점가 안내] → `#/district/:id` 하나뿐 |

- 카드가 뜨면 시트를 접힘으로 내린다. 카드의 [×] 를 누르면 내리기 전 스냅으로 돌아간다 (그 사이 사용자가 시트를 직접 끌었으면 기억을 버린다).
- 전체 스냅에서 카드를 띄울 때는 시트가 멈춘 뒤(340ms) 띄운다. 시트를 전체로 올리면 선택이 풀린다.
- 지도 패딩(위 = 필터 바, 아래 = 시트 + 카드)은 실측값이다.

## 4. 가게를 고르는 길 (점포 → 지도 핀 → 카드)

| 진입 | 동작 |
|---|---|
| 시트 인기 매장 카드 · 둘러보기 탭 인기 카드 | `showStoreOnMap` |
| S15 목록 행 | `closeAll()` 후 `showStoreOnMap` (상세로 바로 가지 않는다) |
| 지도 핀 | 카드를 바로 띄운다 |

`showStoreOnMap`: 탭이 상점가가 아니면 옮긴다 → **업종 칩은 지운다**(전체로) → 온누리 필터는 그 가게가 비가맹일 때만 끈다 → 검색어는 그 가게가 안 걸릴 때만 지운다 → 핀을 켜고 카드를 띄운다 → 토스트 「상점가 탭으로 이동했습니다」(탭 이동 여부와 관계없이 호출된다).

## 5. 다른 상점가로 가는 길

| 진입 | 동작 |
|---|---|
| S13 줄 · 둘러보기 탭 줄 · 축제 상세의 다른 상점가 (2026-10-19 변경) | `#/district/{id}` → S13-A 상점가 안내. **상점가 탭으로 옮기지 않는다** — 둘러보기 안에 머문다. 시트의 근처 3곳 줄은 시트가 다시 목록이 되며 없어졌다 |
| S13-A 의 [점포 둘러보기] (지금 상점가 제외) | `#/district/{id}/map` → **DistrictMap** — 상점가 탭(S03)과 같은 짜임: 지도 위 검색창 + 업종 칩, 점포마다 핀, 바텀시트(3단 스냅)의 점포 목록(20곳씩 · 쪽 나누기). 행/핀을 누르면 시트가 접히고 미리보기 카드([길찾기] · [상세 보기]) → 점포 상세 · 길찾기. 시트 제어 줄은 상점가 탭과 같다 — [온누리 가맹점] 칩 + 거리순(QR 스캔 지점 기준, 값은 미표기)/인기순 드롭다운. 점포별 온누리 가맹 여부는 자료에 없어 시연용으로 시 안내의 수만큼 표시한다. 점포 자료가 있는 상점가는 동백이음길(`dongbaekium`, 실제 190곳)과 동백역(`dongbaekstn`, 실제 459곳) · 동백중심상가(`dongbaekjung`, 실제 630곳)이고 나머지는 중심 핀 + 「준비 중」. 이 점포들의 길찾기도 다른 점포와 같이 **QR 스캔 지점(둔전)에서 출발**한다 — 수십 km 길이로 안내된다(사용자 판단, 2026-10-19) |
| S03-E 의 상점가 줄 | 지도를 거치지 않고 바로 `#/district/{id}` (S13-A) |

- 축제 상세의 「상권」 줄: 현재 상점가 축제면 상점가 탭으로, 다른 상점가면 S13-A(`#/district/{id}`).
- 이 화면들의 상점가 줄은 용인시 누리집으로 나가지 않는다 (줄 동작이 모두 위 표의 앱 안 이동이다).

## 6. S15 가게 전체보기 (`StoreList`)

제목: `{shortName(district)} 전체매장` = 「동백이음길 골목형 상점가 전체매장」. 뒤로가기만 있다(`DetailPage`).

| 요소 | 규칙 |
|---|---|
| 검색창 | 상호명(`name`) 또는 업종(`biz`) 부분 일치. `data-store-search` 로 포커스 대상 지정 |
| 업종 칩 | **없다** (2026-10-19, 사용자 요청). 업종은 검색창(`biz` 부분 일치)으로 찾는다. 셸의 `cats` 값은 남아 있어(지도 위 칩이 정한 값) 목록은 그 조건을 따르고 제어 줄 제목에 「음식 N곳」처럼 드러난다 |
| 제어 줄 | 제목 `{전체 \| 업종명 \| 업종 N종} {N}곳`(고른 칩 0개 = 전체, 1개 = 그 이름, 2개 이상 = 「업종 N종」). 정렬 거리순 / 인기순. 오른쪽 온누리 칩(켜짐 = 가맹점만) |
| 정렬 | 거리순: `dist` 오름차순. 인기순: `views` 내림차순, 동률은 `dist` |
| 목록 | `StoreRow`. 행을 누르면 4장의 길로 간다 |
| 쪽 나누기 | 20곳(`PAGE_SIZE`). 「{N}곳 중 a–b」 + `Pagination`. 쪽 번호가 범위를 넘으면 마지막 쪽으로 맞춘다 |
| 빈 결과 | `Notice(danger, sm)` 「조건에 맞는 매장이 없습니다.」 — 글자색도 붉다(red-800) |
| 고지 | 「점포 정보 2026.03. 기준. 안내 정보는 참고용입니다.」 |
| 스크롤 | 조건 · 쪽이 바뀌면 맨 위로 (`scrollKey`) |

- 상태(검색어 · 업종 · 온누리 · 정렬 · 쪽)는 `MainApp` 이 들고 있다. 상세를 보고 돌아와도 유지되고 지도 핀이 같은 `storeRows` 를 본다. 칩 · 온누리 · 검색 · 정렬이 바뀌면 쪽은 1 로 돌아간다.
- 점포 227곳 · 온누리 61곳(받은 표의 가맹 칸) · 칩별 개수는 `current.js` 가 점포 자료에서 센 값이다.

## 7. S13 상점가 전체보기 (`DistrictList`)

제목 「용인 골목형 상점가」.

| 요소 | 규칙 |
|---|---|
| 구 칩 | [전체] + 처인구 · 기흥구 · 수지구(`GU_ORDER`). 각 칩에 개수. sticky |
| 대상 | `DISTRICTS` 전체 — 현재 상점가(동백이음길, 거리 0)를 포함한 표 전체 (원 자료 주석 기준 32곳) |
| 정렬 | `byDistrictNear` (거리, 동률은 이름순). 정렬 컨트롤은 없다 |
| 줄 | `DistrictRow`. [축제] 배지를 켜지 않는다. 누르면 5장 S13-A |
| 쪽 나누기 | 10곳(`DISTRICT_LIST_PAGE_SIZE`). 「{N}곳 중 a–b」 + `Pagination`. 구를 바꾸면 1쪽 |
| 빈 결과 | 「해당하는 상점가가 없습니다」 / 「다른 구를 선택해 보세요.」 |
| 고지 | 「안내 정보는 참고용이며, 점포 수와 온누리 가맹 수는 시 안내 기준이라 실제와 다를 수 있습니다.」(기준일 없음, 119 없음) |

- 구 칩 · 쪽 상태는 화면 안에 있다. 닫았다 다시 열면 [전체] · 1쪽으로 시작한다 (S15 와 다르다).
- 열리는 길: 시트의 [주변 골목형 상점가 전체보기 >], 둘러보기 탭의 [전체보기].

## 8. S13-A 다른 상점가 안내 (`DistrictInfo`)

- 열리는 길: 카드의 [상점가 안내], S03-E 줄, 딥링크 `#/district/:id`. 대상은 `DISTRICTS` 전체이므로 현재 상점가(`dunjeon`)도 열린다. 못 찾으면 토스트 「정보를 찾을 수 없습니다」 후 뒤로.
- 가진 자료만 보인다. 점포 목록 · 인기 매장 · 코스는 없다 (인기 · 코스는 현재 상점가 한 곳 기준이라 다른 상점가에 붙이지 않는다. 점포 자료가 있는 동백역 · 동백중심상가는 [점포 둘러보기]가 선다).

| 요소 | 규칙 |
|---|---|
| 제목 · 헤더 | 상점가 이름(「…골목형상점가」 앞을 띄워 「… 골목형상점가」) · 아이콘 · 소재지 한 줄(`구 + 행정동 + 도로명`, 도로명이 읍·면·동으로 시작하면 행정동 생략) |
| 사진 | `PhotoStrip` — `district.images` 가 없으면 자리표시 |
| 상점가 현황(정보 표, 위에 「상점가 현황」 제목) | 가게 수 「N곳」 / 온누리 가맹점 「N곳」, 값이 없으면(`onnuri == null`) 「-」(0곳으로 적지 않는다) / 거리(`dist` 0 = 「현 위치」, 1000m 이상은 km 소수 한 자리) |
| 축제 및 행사 | 있을 때만 `FestivalCard` → `#/festival/{id}`. 제목은 축제 상태와 상관없이 「축제 및 행사」 하나 |
| 고지 | 「점포 수와 온누리 가맹 수는 시 안내 기준이라 실제와 다를 수 있습니다. 안내 정보는 참고용입니다.」 |
| 닫기 | 뒤로(`onBack`) · 닫기(`onClose` = `closeAll`) |

- 홍보성 정보(소개 문구 · 대표 사진)는 자료가 없다 — 「미정」(`direction_v2_rules.md` 9장).

## 9. S03-E 상점가 없음 (`DistrictEmpty`)

- 켜는 법: `?district=none` (검수 플래그. 실서비스에서는 서버가 넘기는 값). 실제 QR 지점은 동백이음길 하나뿐이라 이 상태에 들어가지 않는다.
- 이 상태에서 달라지는 것: 시트가 점포 목록 자리에 `DistrictEmpty` 를 그린다 · 필터 바(검색 · 칩)를 숨긴다 · 점포 핀을 찍지 않는다 · 시트 제목 「상점가」 · 오른쪽 `DistrictSummary` 없음 · 코치마크 둘째 걸음 제외 · 둘러보기 탭도 현재 상점가가 없는 축소 상태가 된다.
- 지도에는 가까운 상점가 3곳(`NEARBY_DISTRICT_COUNT`)의 핀이 찍힌다.

| 요소 | 내용 |
|---|---|
| 빈 상태 | 조아용(curious) · 「가까운 골목형 상점가가 없습니다」 · 「{기준점 이름} 주변에는 지정된 골목형 상점가가 없습니다.」 |
| 안내 상자 | 「주변 공공시설은 상점가와 관계없이 안내됩니다.」 + 「AED, 화장실, 쉼터, 대피소 정보를 확인할 수 있습니다.」 + 글자 링크 [공공시설 탭으로](탭 전환) |
| 가볼 만한 상점가 | 거리순 3곳 `DistrictRow`(축제 배지 없음). 줄 → `#/district/{id}` |
| 버튼 | [상점가 {DISTRICT_COUNT}곳 전체 보기] → 둘러보기 탭으로 전환 (S13 으로 가지 않는다) |
| 고지 | 「상점가 지정 현황 2026.07 기준. 안내 정보는 참고용입니다.」 |

- 화면에 임계 거리 숫자를 적지 않는다.
